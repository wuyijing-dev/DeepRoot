# 下一步可以看什么

你已经走完 DeepRoot **1.9**（当前推荐 **`v1.9.1`**）：自有 DTS、virtio-blk、SMP、自研 shell、**in-RAM 目录树**。  

按根目录 `VERSION`：**先不急着上 framebuffer**，也**先不跳到 1.10**。接下来继续用 **较长的 1.9.y** 把文件系统做深（持久写、fd…）；显示推到更后的系列。版本号会**放慢**——同一主题多用 `SUBLEVEL`。

## 1. 巩固

- `mkdir` / `cd` / `pwd` / `rm` / `rmdir` 与 `>` 写嵌套路径各试一遍  
- 读 `kernel/src/vfs.rs` 与 [1.9 章](../path/13-fs19.md)  
- 回看 [1.8 shell](../path/12-shell18.md)

## 2. 官方下一站（实用优先）

| 系列 | 目标 | 节奏提示 |
|---|---|---|
| **1.9.y** | 文件系统加深（落盘、fd…） | **继续停在本系列** |
| **1.10** | 可加载模块 / 动态服务器 | FS 够教了再开 |
| **1.11** | 更多实用运行时（工具、I/O 打磨…） | 从 backlog 选做 |
| **1.12** | Framebuffer 简易 UI（**延后**） | 实用主题够用后再开 |
| **2.0** | 平台集成发布 | 不赶；主题齐了再标 |

## 3. 自己玩

- 给 VFS 加简单配额或更大 `FILE_MAX`  
- 在 shell 里做 `cp`（仍走现有 syscall）  
- 对照 `VERSION` 勾选下一小段 W3/W4

心态：DeepRoot 是**自研能力微内核**；学别人可以，**不要**把 Linux VFS 整棵搬进来。
