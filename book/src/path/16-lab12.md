# 1.11–1.12：fd 表与实用 shell 工具

对齐：**v1.12.0**（含 **1.11.1** fd）。

## 1.11.1 文件描述符

- `SYS_OPEN` / `CLOSE` / `FD_READ` / `FD_WRITE` / `LSEEK`（32–36）
- 每任务最多 8 个 fd；路径在 open 时快照
- shell：`hexdump` / `stat` 走 fd

## 1.12.0 实用实验工具

- `sleep MS` / `time` / `ledger` / `caps`
- `SYS_SLEEP_MS`（37）、`SYS_CAP_DUMP`（38）；`SYS_LEDGER_DUMP` 已有
- virtio-console 仍延后（串口 debug 路径继续用）

## 动手

```text
echo hello > note.txt
hexdump note.txt
stat note.txt
sleep 50
time
ledger
caps
```

## 验收

```bash
git checkout v1.12.0
./scripts/run-qemu.sh --smoke
```

应见 `init: fd read ok`、`init: slept`、`Root Ledger`、`CapSpace`，以及双启动 durable 证明。
