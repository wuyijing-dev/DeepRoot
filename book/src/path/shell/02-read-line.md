# `read_line` 与共享串口

这一页只讲：**你敲的每个键怎么变成一行命令。**

## 1. 逐字节，不是「终端驱动整行」

shell 循环调用读串口字节（经 syscall）：

- 可打印字符：回显并写入行缓冲  
- `\r` / `\n`：结束本行  
- 退格：擦掉缓冲最后一个字符并回显擦除序列  
- 暂无数据：常见返回 `ERR_AGAIN`，`yield` 后再试  

## 2. 为什么要 `yield`？

**1.7** 起默认双 hart：ping/console 常在 hart0，init/shell 在 hart1；串口仍共享。
shell 若忙等空串口，会饿死别人；让出 CPU 后调度器才能转一圈。

## 3. 缓冲区上限

行缓冲很小（约 64 字节）。超长粘贴会被截断——别当 bash 用。
