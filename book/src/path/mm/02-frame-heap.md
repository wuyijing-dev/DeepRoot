# 0.2.2 frame allocator 与 heap

这一页只讲：**页从哪里来，普通动态分配又从哪里来。**

## 1. 两类分配

### frame allocator

- 以页为单位
- 给页表、用户映射、内核页用

### kernel heap

- 给 `alloc` 世界用
- 适合较小、较灵活的数据结构

## 2. 为什么要分开

因为“我要一页 4KiB 可映射内存”和“我要一小块 Rust 动态对象”不是同一件事。  
把两者混成一层，会让后续页表和 ELF 加载更难理解。

## 3. 阅读建议

先看：

- `frame::init`
- `frame::alloc`
- heap 初始化入口

先建立感觉：  
**内核不是凭空 `Box::new` 出整个系统的，一些路径必须直接拿物理页。**
