# 0.2.4 为什么这决定 ELF 装载

这一页只回答：**为什么 0.2 的页表工作，其实已经在为 1.1 的 `spawn/exec` 铺路。**

## 1. ELF 不是“读进内存就能跑”

后面的加载器要做的是：

1. 读 ELF 段
2. 分配物理页
3. 按目标虚址映射到页表
4. 设置执行/写权限
5. 让 `sepc` 指向入口

其中第 2–4 步都建立在 0.2 的基础设施上。

## 2. 如果 0.2 没搞对，后面会看到什么

- 进用户态就 page fault
- `exec failed`
- 栈地址可疑
- `satp` 切换后直接炸

因此读 0.2 时别把它当“纯理论章”。  
它其实是在给 1.1 的用户态可执行文件铺水泥。
