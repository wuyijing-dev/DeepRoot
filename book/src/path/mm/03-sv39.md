# 0.2.3 Sv39 身份映射

这一页只讲：**DeepRoot 早期为什么先做 identity map。**

## 1. Sv39 是什么

RISC-V 64 位常见分页模式之一。  
对新手先记住一句话：

```text
虚拟地址 -> 页表 -> 物理地址
```

## 2. identity map 的教学价值

在早期阶段，把一段 RAM 做成：

```text
VA == PA
```

能让你少掉很多“地址搬运”的心智负担。  
这样先把页表、切换、访问打通，再去理解更复杂的用户态地址空间。

## 3. 关键文件

- `kernel/src/mm/sv39.rs`

你需要认几个最关键的位：

- `V`
- `R`
- `W`
- `X`
- `U`

## 4. 为什么这一步和用户态暂时还不是一回事

早期 identity map 更像“内核先站稳脚跟”。  
真正每任务单独页表、用户 `U` 位映射，是 1.1 那一批才重点讲的事情。
