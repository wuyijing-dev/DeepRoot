# 1.13 服务命名 / 发现（对齐 v1.13.0）

对齐：**v1.13.0**。

## 这一站解决什么？

以前客户端只能记住 **slot / badge**。  
**1.13.0** 增加按**名字**解析：`SYS_SERVICE_LOOKUP` 查 registry，给调用者 mint 一张 Endpoint。

- canopy：`ping` / `console` 在 bring-up 时注册  
- 动态模块：`modload` / `spawn_server` 用 basename 注册（如 `mynote`）  
- shell：`lookup NAME`（别名 `svc`）

## 动手

```text
modules
lookup ping
lookup mynote
```

## 验收

```bash
git checkout v1.13.0
./scripts/run-qemu.sh --smoke
```

应出现 `module: loaded 'ping'`、`init: lookup ping ok`、`service: resolved 'mynote'`、`init: lookup mynote ok`。
