# 1.9 文件系统加深（对齐 v1.9.0）

对齐：**v1.9.0**（系列会在 `1.9.y` 上停留较久）。

当前推荐标签：**`v1.9.0`**。

## 这一站解决什么？

1.8 之前的教学 FS 基本是**扁平**名字：embed 文件、DRFS 根目录条目、以及 1.8 的 scratch 写。  
**1.9.0** 先落地一层 **in-RAM VFS 树**：真正的目录结点、`mkdir` / `rmdir` / `rm`、以及与 shell 一致的 **kernel cwd**。

后续 `1.9.y` 再慢慢做：更大的持久 DRFS、fd 表等——**不要急着跳到 1.10**。

## 分层（读代码时心里要有图）

| 层 | 职责（1.9.0） |
|---|---|
| Embed ramfs | 根上的 ELF/文本（`hello`、`version`…） |
| `kernel/src/vfs.rs` | 用户创建的目录与嵌套文件（内存） |
| DRFS / virtio-blk | 根上的 on-disk 文本（仍扁平） |
| `kernel/src/fs.rs` | 统一 facade：`ls`/`cat`/`write`/`mkdir`… |

## 动手最短路径

```text
mkdir demo
cd demo
pwd
echo hi > a.txt
cat a.txt
ls
cd /
ls demo
rmdir demo          # 非空会失败
rm demo/a.txt
rmdir demo
```
