# 0.1.2 跟读 `boot.rs`

这一页只回答：**`_start` 在进 Rust 之前到底做了什么准备。**

## 1. 关键动作

1. 保存 `a0/a1`
2. 设定 `sp`
3. 清 BSS
4. 恢复 `a0/a1`
5. `call kernel_main`

## 2. 为什么保存 `a0/a1`

因为 OpenSBI 通过它们把：

- `hartid`
- `dtb_pa`

传给内核。  
而清 BSS 和后续动作可能会覆盖寄存器，所以要先暂存。

## 3. 为什么清 BSS

未初始化全局变量依赖 BSS 全 0。  
这一层如果错了，后面很多“看似高级”的 bug 其实都只是启动基础没做好。

## 4. 为什么这里还不是“正常 Rust 世界”

此时还没有：

- 内核堆
- 用户态
- trap frame
- 稳定的页表环境

所以这段汇编几乎每一行都不是“优化”，而是必需品。
