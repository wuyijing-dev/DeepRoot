# 1.3.1 ramfs 模型

这一页只讲：**DeepRoot 现在的“文件系统”到底是什么。**

## 1. 它是

一张静态表：

```text
名字 -> &'static [u8]
```

## 2. 它不是

- 持久磁盘文件系统
- 用户态 VFS
- 可写目录树

## 3. 为什么教学上这样做

因为它把问题压缩成：

```text
找到一段字节
把它当文本显示
或把它当 ELF 执行
```

这样你先学会“路径 -> 字节 -> 行为”，再去碰更重的 FS 设计。
