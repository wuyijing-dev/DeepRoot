# 1.3.4 `SYS_SPAWN` vs `SYS_EXEC`

这一页只讲：**为什么既有 `spawn(blob_id)`，又有 `exec(path)`。**

## 1. `SYS_SPAWN`

- 参数是 blob id
- 目前更像教学脚手架
- 适合最小演示

## 2. `SYS_EXEC`

- 参数是路径
- 数据来自 ramfs
- 更像真正操作系统里的“按名字运行”

## 3. 心智模型

```text
SPAWN = 内核内置演示入口
EXEC  = 面向用户的路径执行接口
```

## 4. 为什么两者都保留

因为它们帮助你看到系统是怎样从：

```text
硬编码 demo
-> 像文件系统一样的执行接口
```

逐步长出来的。
