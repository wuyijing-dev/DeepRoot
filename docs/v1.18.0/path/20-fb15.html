DeepRoot 学习笔记

1.15.0 Framebuffer：ramfb + draw

对齐：v1.15.0（像素原语）；菜单见 1.15.1。

串口仍是主交互。本版在 QEMU 上挂 -device ramfb，由 drivers/fbdemo（embed /fbdemo）经 fw_cfg DMA 配置像素缓冲并画图。

内核原语

能力说明
FDT qemu,fw-cfg-mmioDTS fw-cfg@10100000
SYS_MMIO_FWCFGmint MMIO Frame
FRAME_ALLOC_N（最大 512 页）连续像素缓冲
FRAME_PHYS / FRAME_MAPDMA 地址与 map

几何常量在 deeproot-abi：FB_WIDTH=320、FB_HEIGHT=240、XR24。

/fbdemo（源码：drivers/fbdemo）

  1. map fw-cfg；找 etc/ramfb
  2. 写 RamFBCfg（BE）
  3. clear / put_pixel / fill_rect
  4. 日志：fbdemo: ramfb ok → clear ok → fill_rect ok
  5. 然后 exit（把显示交给 /fbmenu）

验收

git checkout v1.15.0
./scripts/run-qemu.sh --smoke

（-nographic 即可。）
