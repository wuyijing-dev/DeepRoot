DeepRoot 学习笔记

1.11 文件系统持久化（对齐 v1.11.0）

对齐：v1.11.0。

当前推荐标签：v1.11.0。

这一站解决什么？

1.9 的目录 / > 写的是 in-RAM VFS，重启就没了。
1.11.0 把根路径上的创建/覆盖/追加接到 DRFS（virtio-blk），重启后还在。

  • 根路径 echo hi > note.txt / >> → SYS_FS_WRITE / SYS_FS_APPEND → block::put_file / append_file
  • 子目录路径仍走 VFS（未持久化）
  • init 写入 durable.txt；第二次启动内核打印 block: durable.txt survived reboot

动手

echo hello > note.txt
cat note.txt
echo more >> note.txt
cat note.txt
ls
# 退出 QEMU 后再 ./scripts/run-qemu.sh，应仍能 cat note.txt / durable.txt

验收

git checkout v1.11.0
./scripts/run-qemu.sh --smoke

smoke 会 启动两次：第一次 format + init: durable DRFS written；第二次 found existing DRFS + durable.txt survived reboot。
