DeepRoot 学习笔记

学习路线图（详细版）

DeepRoot 用类似 Linux 的版本号：

MAJOR.PATCHLEVEL.SUBLEVEL
段含义初学者怎么用
MAJORABI 大断裂或平台跃迁（2.0 = 集成发布，不赶）文档基线在 1.x，当前推荐 v1.9.0
PATCHLEVEL一个主题系列（放慢；系列内多用 SUBLEVEL）按 0.1 → … → 1.9 读文档
SUBLEVEL系列内分段落地与打磨例：1.9.0 → 1.9.1 → …

完整注释清单在仓库根目录 VERSION。

3. 推荐学习节奏

  1. 第 0 天：只做 第一次启动，不改代码。
  2. 然后：按章节顺序读到 1.9；每章至少做一半「动手验证」。
  3. 卡壳时：先查 常见问题。
  4. 想创造时：完成 1.3 后再做 自己写用户程序。

请固定 v1.9.0（或页首选择器打开对应冻结快照），否则日志和截图对不上。
